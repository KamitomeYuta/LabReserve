## ทำความเข้าใจ

Authentication ตอบว่าใคร: login ตรวจ password hash แล้วออก random session token Authorization ตอบว่าทำอะไรได้: adminOnly ตรวจ role และ detail จำกัด user_id ทั้งสองต้องอยู่ server เพราะคนส่ง request ไม่จำเป็นต้องใช้ UI ของเรา

Database เก็บ hash ของ session token ไม่เก็บ token ที่ใช้เป็น cookie โดยตรง Cookie HttpOnly ลดการอ่าน token ด้วย JavaScript แต่ browser ยังแนบ cookie ใน request จึงต้องป้องกัน CSRF ด้วย signed token, custom header และ Origin check ร่วมกัน

logout ลบ session row ทำให้ cookie เก่าใช้ต่อไม่ได้ Login ใหม่หมุน session; expiry ตรวจทุก request ไม่ใช้เพียง cookie expiry ด้าน browser ตรวจ Network และ storage ได้ แต่ห้ามนำค่าจริงไปลง screenshot สาธารณะ

## ลงมือทดลอง

คำสั่งจากรากโปรเจกต์ (โฟลเดอร์ที่มี package.json):

```bash
npm run test:integration
```

**ผลที่ควรเห็น:** กรณี missing CSRF/foreign Origin ได้ 403; หลัง logout/หมดอายุได้ 401; ข้ามบัญชีได้ 404

**ถ้าติดปัญหา:** Secure cookie ไม่ส่งผ่าน HTTP ใน production จึงต้องตั้ง HTTPS จริง; ถ้า dev เปิด 127.0.0.1 แต่ origin ตั้ง localhost จะถูกปฏิเสธโดยตั้งใจ

## แบบฝึกหัด

อธิบายเส้นทางโจมตีหากซ่อนปุ่มผู้ดูแลแต่เอา adminOnly ออกจาก server แล้วชี้ test ที่จะจับความผิดนี้
