## ทำความเข้าใจ

เริ่มจาก basics.mjs: const ผูกชื่อกับค่า object รวมคุณสมบัติของอุปกรณ์หนึ่งชิ้น ส่วน array เก็บหลายชิ้น function รับ input และ return output เงื่อนไข if ใช้ตัดสินว่าจะยอมให้ยืมหรือไม่

find คืนสมาชิกแรกที่ตรงเงื่อนไขหรือ undefined; filter คืน array ของรายการที่ตรงเงื่อนไข; map สร้าง array ใหม่โดยแปลงแต่ละรายการ เครื่องหมาย ... ใน {...item, borrowed:true} คัดลอกคุณสมบัติแล้วเปลี่ยน borrowed

โค้ด inventory.ts เป็นเวอร์ชันมีชนิดข้อมูลซึ่งจะเรียนในบท 03 ตอนนี้อ่านเฉพาะ logic: หาอุปกรณ์ → ไม่พบให้ throw → ถูกยืมแล้วให้ throw → คืน array ใหม่ อย่าข้าม error case เพราะมันคือส่วนหนึ่งของ requirement

CLI ตัวอย่างเริ่มจากข้อมูลจำลองใหม่ทุกครั้ง จึงยังไม่มี persistence การรัน borrow ครั้งใหม่ไม่ใช่การยืมซ้ำจากครั้งก่อน

## ลงมือทดลอง

คำสั่งจากรากโปรเจกต์ (โฟลเดอร์ที่มี package.json):

```bash
node examples/basics.mjs
npm run lesson:cli -- list
npm run lesson:cli -- borrow CAM-001
npm run lesson:cli -- search MIC
```

**ผลที่ควรเห็น:** ตัวอย่าง JavaScript พิมพ์ CAM-001 true และ original false; CLI แสดง borrowed=true สำหรับกล้อง

**ถ้าติดปัญหา:** ถ้า node/npm ไม่พบ ให้ตรวจ PATH และ Node version; ถ้าขึ้น item not found ให้ตรวจ asset code ที่พิมพ์

## แบบฝึกหัด

เพิ่มฟังก์ชัน available(items) ที่คืนเฉพาะอุปกรณ์ยังไม่ถูกยืม โดยไม่เปลี่ยน array ต้นฉบับ
