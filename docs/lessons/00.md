## ทำความเข้าใจ

เปิด http://localhost:3000 แล้วใช้บัญชีสมาชิก demo เลือกกล้องและจองเวลาวันพรุ่งนี้ ก่อนกดยืนยัน เปิด Developer Tools → Network และเลือก Fetch/XHR หลังจองให้เปิด request POST /api/v1/reservations

ดู Request Payload: equipmentId คือของที่จะจอง startAt/endAt คือเวลา ดู Response: 201 หมายถึงสร้างแล้ว และ item.id คือเลขอ้างอิง ไม่ใช่รหัสของอุปกรณ์ Response มาจาก API ซึ่งเขียนฐานข้อมูลแล้ว หน้าจอไม่ได้ถือความจริงไว้เอง

ตามชื่อฟังก์ชัน book ในหน้า Equipment ไป api() แล้วไป route POST / และ service book() ยังไม่ต้องเข้าใจทุกบรรทัด ให้จดว่าแต่ละจุดรับอะไรและส่งอะไร หลังยกเลิกให้ refresh หน้า ประวัติยังอยู่เพราะบันทึกใน PostgreSQL

## ลงมือทดลอง

คำสั่งจากรากโปรเจกต์ (โฟลเดอร์ที่มี package.json):

```bash
docker compose ps
docker compose logs --tail=20 app
```

**ผลที่ควรเห็น:** app และ db healthy; หลังจองเห็น HTTP 201 และเมื่อยกเลิกเห็น HTTP 200 พร้อม status=cancelled

**ถ้าติดปัญหา:** Connection refused มักเกิดจาก Docker/app ยังไม่ทำงาน; ถ้า 403 ให้ตรวจว่าเปิด localhost และ origin ตรงกับ configuration
