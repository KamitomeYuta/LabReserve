## ทำความเข้าใจ

Component คือฟังก์ชันที่คืน UI Props เป็นข้อมูลจาก parent State เป็นข้อมูลที่เปลี่ยนแล้วต้อง render ใหม่ เช่น search/page/start/end ใช้ setState แทนการแก้ตัวแปรเดิมโดยตรง

useLoad เริ่ม request เมื่อ key เปลี่ยน เก็บ data/error/busy และมี active flag กัน request เก่าที่เสร็จช้ากว่าเขียนทับผลใหม่ Form submit เรียก preventDefault เพื่อไม่ reload ทั้งหน้า ก่อนส่งเวลาใช้ bangkokToIso ไม่ใช้ new Date(datetimeLocal) ซึ่งตีความตาม timezone ของเครื่อง

ฝึกอ่านสี่สถานะ: loading ระหว่างรอ, empty เมื่อผลเป็นศูนย์, error เมื่อส่งไม่สำเร็จ, success เมื่อได้ข้อมูล UI ซ่อนปุ่มตามสิทธิ์เพื่อช่วยผู้ใช้ แต่ server ยังต้องตรวจซ้ำ

## ลงมือทดลอง

คำสั่งจากรากโปรเจกต์ (โฟลเดอร์ที่มี package.json):

```bash
npm run dev
```

**ผลที่ควรเห็น:** เปิด localhost:5173 ได้ ค้นหาอุปกรณ์และเปลี่ยนหน้าได้; เวลาที่ส่งมี UTC Z หลังแปลงจาก UTC+7

**ถ้าติดปัญหา:** ถ้า API เรียกไม่ได้ให้ตรวจ Vite proxy กับ API port; อย่าติดตั้ง CORS แบบอนุญาตทุก origin เพื่อแก้แบบเดาสุ่ม

## แบบฝึกหัด

ลองค้นหาคำที่ไม่มีอุปกรณ์และหยุด API ชั่วคราวใน dev เพื่อสังเกต empty กับ error ว่าแสดงต่างกันอย่างไร
