## ทำความเข้าใจ

interface Item บอกว่าแต่ละ object ต้องมี id/name เป็น string และ borrowed เป็น boolean เครื่องหมาย : Item[] บอกว่าเป็น array ของ Item TypeScript ช่วยตรวจการใช้ข้อมูลผิดชนิดตอน typecheck แต่ไม่ได้ทำให้ JSON ที่คนอื่นส่งมาปลอดภัย

Role เป็น union คือ member หรือ admin เท่านั้น ถ้า error เป็น unknown ต้องเช็ก error instanceof Error ก่อนอ่าน message นี่คือ narrowing ที่ทำให้ compiler รู้ข้อมูลเพิ่ม

อ่าน bookingSchema: equipmentId ต้องเป็น UUID และเวลาต้องมี offset Zod parse ตรวจข้อมูลจริงตอน runtime และ throw เมื่อผิด schema ส่วน type ของ DTO ใช้ช่วย editor และ compiler ทั้งสองทำงานคนละช่วง

## ลงมือทดลอง

คำสั่งจากรากโปรเจกต์ (โฟลเดอร์ที่มี package.json):

```bash
npm run typecheck
npm test
```

**ผลที่ควรเห็น:** typecheck จบโดยไม่มี error และ unit tests ผ่าน

**ถ้าติดปัญหา:** TypeScript import ลงท้าย .js ทั้งที่ไฟล์ต้นฉบับ .ts เป็นรูปแบบสำหรับ Node ESM หลัง compile อย่าเปลี่ยนสุ่มจน build/runtime ต่างกัน

## แบบฝึกหัด

ลองกำหนด borrowed เป็น string ในตัวแปร Item แล้วรัน typecheck อ่าน error จากนั้นคืนเป็น boolean; ลองส่งเวลาไม่มี offset เข้า intervalSchema ใน test
