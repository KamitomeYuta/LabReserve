## ทำความเข้าใจ

Terminal รันคำสั่งใน working directory ปัจจุบัน ใช้ pwd ตรวจตำแหน่ง และ ls ดูไฟล์ npm run อ่านชื่อ script จาก package.json เช่น npm test เรียก Vitest ไม่ใช่คำสั่งลึกลับของระบบ

Git เก็บ snapshot ของไฟล์ที่เลือก ไม่ใช่ backup ทุกอย่างในเครื่อง git diff แสดงสิ่งที่แก้แต่ยังไม่ stage; git diff --staged แสดงสิ่งที่จะ commit .gitignore กัน node_modules, .env และ backup ไม่ให้เข้าประวัติโดยไม่ตั้งใจ

เมื่อเจอ error ให้อ่านข้อความแรกและ stack frame ที่ชี้เข้าไฟล์เรา แยก validation error, business conflict, database error และ environment error ออกจากกัน ตั้ง breakpoint ใน assertBookingWindow หรือเพิ่ม log เฉพาะค่าที่ไม่เป็นข้อมูลลับ แล้วเปรียบเทียบสิ่งที่คาดกับสิ่งที่เกิด

## ลงมือทดลอง

คำสั่งจากรากโปรเจกต์ (โฟลเดอร์ที่มี package.json):

```bash
pwd
git status --short
git log --oneline -5
npm run lesson:cli -- borrow UNKNOWN
```

**ผลที่ควรเห็น:** คำสั่งสุดท้ายจบด้วย exit code 1 และ item not found ซึ่งเป็น failure ที่ตั้งใจให้ลองอ่าน

**ถ้าติดปัญหา:** ถ้า npm หา package.json ไม่พบ แสดงว่าอยู่ผิดโฟลเดอร์; อย่าใช้ git reset --hard เพื่อแก้ error โดยไม่เข้าใจสิ่งที่จะหาย

## แบบฝึกหัด

แก้ข้อความเล็กน้อยในเอกสารหนึ่งไฟล์ อ่าน git diff แล้วสร้าง commit ที่บอกเหตุผลของการแก้
