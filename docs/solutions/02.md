# เฉลย 02 — Terminal, Git และ debugging

```bash
git diff -- docs/portfolio.md
git add docs/portfolio.md
git diff --staged
git commit -m "docs: record my first learning experiment"
```

ทำหลังแก้ไฟล์จริงเท่านั้น .env อาจมี credentials ซึ่งประวัติ Git เก็บไว้แม้ลบจากไฟล์ปัจจุบันแล้ว

**สิ่งที่ต้องพิสูจน์เอง:** ทำแบบฝึกซ้ำโดยไม่เปิดเฉลย แล้วบอกว่าการเปลี่ยนแปลงแบบใดจะทำให้ผลผิด และคุณจะตรวจพบอย่างไร
