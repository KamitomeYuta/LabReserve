# เฉลย 09 — React: จากข้อมูลเป็นหน้าจอ

useLoad เก็บ data เก่าไว้ แต่ caller แสดง Loading ขณะ busy และ active=false ใน cleanup ทำให้ผลเก่าถูกทิ้ง UI empty เกิดเมื่อ request สำเร็จแต่ items ว่าง ส่วน network error แสดง ErrorNotice ต่างหาก

**สิ่งที่ต้องพิสูจน์เอง:** ทำแบบฝึกซ้ำโดยไม่เปิดเฉลย แล้วบอกว่าการเปลี่ยนแปลงแบบใดจะทำให้ผลผิด และคุณจะตรวจพบอย่างไร
