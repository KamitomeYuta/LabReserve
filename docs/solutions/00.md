# เฉลย 00 — เปิดระบบและตามหนึ่งคำขอ

บัญชีสมาชิกอีกคนควรได้ 404 เพราะ repository.detail มีเงื่อนไข r.user_id=$3 หรือ role admin การซ่อนลิงก์อย่างเดียวไม่เพียงพอ ข้อมูลยังอยู่หลัง refresh เพราะ transaction commit ไป PostgreSQL แล้ว
