# เฉลย 04 — HTTP, JSON และ asynchronous code

409 เป็น response ปกติในระดับ network แต่ business action ไม่สำเร็จ UI จึงต้องแสดงให้เลือกเวลาใหม่ 204 ไม่มี JSON body client จึงคืน undefined ก่อนเรียก response.json()

**สิ่งที่ต้องพิสูจน์เอง:** ทำแบบฝึกซ้ำโดยไม่เปิดเฉลย แล้วบอกว่าการเปลี่ยนแปลงแบบใดจะทำให้ผลผิด และคุณจะตรวจพบอย่างไร
