# เฉลย 08 — Race condition: ทดลองให้เห็นก่อนแก้

Mutex ใน process ไม่ประสานอีก instance หรือ writer ที่เขียนตรง DB ต้องให้ invariant อยู่ในจุดร่วมคือฐานข้อมูล สำหรับช่วงติดกัน A.end=B.start ต้องไม่ conflict เพราะขอบขวาเป็น exclusive

**สิ่งที่ต้องพิสูจน์เอง:** ทำแบบฝึกซ้ำโดยไม่เปิดเฉลย แล้วบอกว่าการเปลี่ยนแปลงแบบใดจะทำให้ผลผิด และคุณจะตรวจพบอย่างไร
