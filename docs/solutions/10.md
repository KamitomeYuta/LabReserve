# เฉลย 10 — Testing: เลือกหลักฐานให้ตรงกับปัญหา

```ts
const end = new Date('2030-01-02T00:00:00Z');
expect(() => assertCancellation('admin', new Date('2030-01-01'), end, 'repair', end)).toThrow();
```

Coverage วัดการผ่านบรรทัด ไม่ได้วัดว่าทุก interleaving/concurrency case ถูกต้อง Constraint และ transaction ต้องมี integration test กับ DB จริง

**สิ่งที่ต้องพิสูจน์เอง:** ทำแบบฝึกซ้ำโดยไม่เปิดเฉลย แล้วบอกว่าการเปลี่ยนแปลงแบบใดจะทำให้ผลผิด และคุณจะตรวจพบอย่างไร
