# เฉลย 03 — TypeScript และ runtime validation

TypeScript ไม่ป้องกัน network input ต้อง validate และเลือก field ที่ server ยอมรับ Register route ไม่เอา role จาก input ไป insert จึงใช้ default member เสมอ Zod schema รับเฉพาะ field ที่กำหนด

**สิ่งที่ต้องพิสูจน์เอง:** ทำแบบฝึกซ้ำโดยไม่เปิดเฉลย แล้วบอกว่าการเปลี่ยนแปลงแบบใดจะทำให้ผลผิด และคุณจะตรวจพบอย่างไร
