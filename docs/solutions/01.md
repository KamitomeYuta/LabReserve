# เฉลย 01 — JavaScript: ข้อมูล เงื่อนไข และฟังก์ชัน

```ts
export function available(items: Item[]): Item[] {
  return items.filter((item) => !item.borrowed);
}
```

เพิ่ม test ที่มีทั้ง borrowed=true/false แล้วตรวจ id ของผลลัพธ์ และตรวจว่า input ยังเหมือนเดิม ไม่ควรใช้ splice เพราะแก้ array ต้นฉบับ

**สิ่งที่ต้องพิสูจน์เอง:** ทำแบบฝึกซ้ำโดยไม่เปิดเฉลย แล้วบอกว่าการเปลี่ยนแปลงแบบใดจะทำให้ผลผิด และคุณจะตรวจพบอย่างไร
