# เฉลย 11 — Docker, CI, logs และ recovery

Image rollback คืน code เวอร์ชันก่อนโดยยังใช้ข้อมูลปัจจุบัน หาก schema compatible ส่วน restore คืน snapshot ซึ่งอาจทิ้ง writes หลัง backup RPO คือข้อมูลย้อนหลังที่ยอมเสียได้ RTO คือเวลาที่ต้องกู้บริการ ต้องออกแบบจากความต้องการผู้ใช้และพิสูจน์ด้วย drill

**สิ่งที่ต้องพิสูจน์เอง:** ทำแบบฝึกซ้ำโดยไม่เปิดเฉลย แล้วบอกว่าการเปลี่ยนแปลงแบบใดจะทำให้ผลผิด และคุณจะตรวจพบอย่างไร
