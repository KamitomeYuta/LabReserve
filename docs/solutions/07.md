# เฉลย 07 — Authentication, authorization และ CSRF

CSRF token ไม่ยืนยันตัวตน Session ยังต้องผ่าน authenticate Password มี entropy ต่ำและเดาได้จึงใช้ slow password hash; session random 32 bytes มี entropy สูงจึงใช้ fast digest เพื่อ lookup ได้ การเอา adminOnly ออกต้องทำให้ test member POST /equipment ล้ม
