# เฉลย 05 — SQL, constraints และ transaction

```sql
SELECT id, asset_code, name FROM equipment WHERE active = true ORDER BY name, id;
```

Backup ใช้ recovery ย้อน snapshot ไม่ได้ป้องกัน partial write ในแต่ละ request Transaction รับประกันกลุ่ม write ปัจจุบันต้องสำเร็จหรือย้อนทั้งหมด

**สิ่งที่ต้องพิสูจน์เอง:** ทำแบบฝึกซ้ำโดยไม่เปิดเฉลย แล้วบอกว่าการเปลี่ยนแปลงแบบใดจะทำให้ผลผิด และคุณจะตรวจพบอย่างไร
